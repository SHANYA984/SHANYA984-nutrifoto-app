# Nutrifoto — Roadmap de producción

## Cerrado en el MVP
- [x] Perfil y objetivos
- [x] Registro de comidas y actividad
- [x] Análisis estimativo desacoplado del proveedor
- [x] Múltiples alimentos por comida
- [x] Corrección manual y recálculo
- [x] Persistencia local
- [x] Eliminación de datos locales
- [x] Exportación local
- [x] PWA y CI de build
- [x] Validaciones básicas del dominio

## Próxima etapa de producto
1. Backend seguro para análisis de imágenes.
2. Proveedor de visión IA con credenciales exclusivamente del servidor.
3. Base nutricional versionada y trazable.
4. Autenticación y sincronización opcional.
5. Política de privacidad y consentimiento antes de subir imágenes.
6. Pruebas unitarias, integración y dispositivos móviles.
7. Observabilidad, límites de uso y manejo de errores.
8. Deploy de producción y dominio.

## Criterio de aceptación
No considerar Nutrifoto producto clínico ni afirmar precisión médica. Todo resultado de fotografía debe conservar carácter estimativo y permitir corrección del usuario.
