# Checklist de lanzamiento de NutriFoto

## Prueba actual

- [x] PWA instalable desde navegador móvil.
- [x] Perfil adulto.
- [x] Guía diaria de 7 días.
- [x] Registro de comidas.
- [x] Captura de foto desde cámara del teléfono.
- [x] Resultado nutricional editable.
- [x] Resumen diario.
- [x] Registro de actividad.
- [x] Historial local.
- [x] Eliminación de datos locales.
- [x] Modo demo sin coste de proveedor de visión.

## Antes de una beta pública

- [ ] Conectar proveedor real de visión mediante variable de entorno segura.
- [ ] Probar imágenes reales y casos de baja confianza.
- [ ] Añadir autenticación y sincronización opcional.
- [ ] Revisar política de privacidad y consentimiento.
- [ ] Revisar textos de seguridad y límites de uso.
- [ ] Ejecutar pruebas de rendimiento móvil.
- [ ] Probar cámara en Android y iOS.
- [ ] Revisar accesibilidad.
- [ ] Configurar dominio propio si corresponde.

## Marketing

- [ ] Crear video corto de demostración para TikTok.
- [ ] Crear versión vertical para Instagram Reels.
- [ ] Crear plantilla de video para CapCut.
- [ ] Crear página de aterrizaje con enlace a la beta.
- [ ] Crear QR para compartir la app.

## Regla de publicación

No presentar las estimaciones nutricionales como mediciones exactas ni como consejo médico. La versión pública debe explicar claramente sus límites.
