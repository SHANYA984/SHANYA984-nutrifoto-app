# Reglas de seguridad

## Límites obligatorios
- Aplicación exclusivamente para adultos.
- No diagnosticar enfermedades ni interpretar síntomas como diagnóstico.
- No indicar, suspender, cambiar ni ajustar medicamentos.
- No presentar la aplicación como sustituto de un profesional de la salud.
- No generar recomendaciones que puedan ser inseguras ante una condición declarada.
- Ante situaciones que requieran valoración profesional, mostrar una advertencia clara y evitar instrucciones clínicas.

## Fotografías
- La identificación y la porción son estimaciones.
- Nunca presentar gramos, calorías o nutrientes derivados de una foto como mediciones exactas.
- Permitir corrección manual.
- Si la imagen es insuficiente, solicitar una nueva foto o corrección en lugar de inventar precisión.

## Datos
- No almacenar claves API en el código.
- No incluir datos personales o médicos reales en ejemplos, fixtures o documentación.
- Minimizar los datos almacenados.
- Separar identificadores técnicos de información sensible.
- Preparar interfaces para reemplazar proveedores externos sin exponer credenciales al cliente móvil.

## IA
Toda salida de IA se considera no confiable hasta pasar por validación de dominio y seguridad. La aplicación no debe ejecutar automáticamente una recomendación clínica generada por IA.
