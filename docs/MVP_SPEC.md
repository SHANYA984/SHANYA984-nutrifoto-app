# Especificación funcional del MVP

## Usuario objetivo
Adultos que desean registrar alimentación y actividad con apoyo de análisis de fotografías y personalización.

## Funcionalidades

### 1. Onboarding y perfil
Campos mínimos:
- Edad.
- Peso.
- Altura.
- Objetivo.
- Nivel de actividad.
- Condiciones declaradas.

### 2. Foto de alimento
- Capturar con cámara.
- Seleccionar imagen existente.
- Mostrar estado de procesamiento.
- Permitir cancelar.

### 3. Resultado de IA
Mostrar:
- Alimentos candidatos.
- Confianza de identificación cuando esté disponible.
- Porción estimada.
- Calorías estimadas.
- Nutrientes estimados.
- Advertencias relevantes.

El resultado debe indicar claramente que se trata de una estimación y permitir corrección manual.

### 4. Registro de comida
- Fecha y hora.
- Tipo de comida.
- Alimentos.
- Porciones.
- Valores nutricionales estimados.
- Nota opcional.

### 5. Actividad física
- Tipo de actividad.
- Duración.
- Intensidad declarada.
- Registro histórico.

### 6. Resumen
- Comidas registradas.
- Totales estimados del día.
- Actividad registrada.
- Evolución histórica.

## Fuera del MVP
- Diagnóstico médico.
- Prescripción o modificación de medicamentos.
- Sustitución de profesionales.
- Promesas de resultados clínicos.
- Automatización de decisiones médicas.
